事業承継・M&A支援

事業を引き継ぐことは、はたらく人と、その先のお客さまの暮らしを引き継ぐことです。承継の方針づくりから、引き継いだ後の組織づくりまで支えます。

STANCE私たちの立場

数字が合うことと、
人が引き継げることは別のこと。

承継やM&Aは、条件が合えば終わりではありません。引き継いだあとに、職員が辞めてしまう、現場のやり方がぶつかる、といったことが起きれば、事業の価値は大きく損なわれます。

私たちは自ら事業所を経営する会社として、数字だけでなく、人と組織が無理なく引き継げるかを大切にします。組織構造構築支援の知見を生かし、引き継ぎの前後で組織が崩れないように支えます。

MENU支援内容

審査制・初年度は年4件までお受けします。

  1. 01承継方針の整理誰に、いつ、どの形で引き継ぐのかを、経営者と一緒に整理します。
  2. 02後継者の育成判断の基準と役割を言葉にし、後継者が迷わず動ける状態をつくります。
  3. 03引き継ぎの準備組織と業務を見える化し、引き継ぐ側が状況をつかめるようにします。
  4. 04引き継ぎ後の組織づくり新しい体制のもとで、役割・ルール・会議を整え直します。

現在、当社は譲り先・譲受先の紹介や、売り手と買い手の間に入る仲介は行っていません。相手探しが必要な場合は、仲介会社の選び方や進め方について、経営者の側に立って助言します。

NOTICEご相談の前に知っておいていただきたいこと

M&A支援機関登録制度について当社は、中小企業庁の「M&A支援機関登録制度」に登録していません。このため、当社にお支払いいただく費用は「事業承継・M&A補助金」の専門家活用枠の補助の対象になりません。

当社が引き継ぎ先になる場合について当社グループは自ら事業所を運営しているため、ご希望があれば、引き継ぎ先の候補の一つになれます。ただし、ご相談いただいた方が不利にならないよう、次のことをお約束します。
  1. 最初にお伝えします。当社が引き継ぐ可能性があるときは、支援を始める前に書面でお伝えします。
  2. 決めるのはご本人です。当社への譲渡をお断りいただいても、支援の内容は変わりません。
  3. 価格は第三者が評価します。当社が引き継ぐ場合、事業の価値は当社と関係のない税理士などの専門家に評価してもらいます。
  4. ご相談者側にも専門家を。価格や条件の話し合いでは、ご相談者側にも当社と関係のない専門家についてもらうことをおすすめし、必要な場合はご紹介します。

秘密の取り扱いについて初回の面談の前に、当社から秘密保持契約の書面をお渡しし、結んだうえでお話をうかがいます。ご相談の内容は、職員の方や取引先を含め、ご本人の同意なく外部に伝えません。

FLOW進め方

費用は月額制です。方針の整理から引き継ぎ後まで伴走するため、期間と金額は事業の規模と支援の範囲に応じて、面談のあとにお見積りします。

  1. お問い合わせ承継について考えていることをお聞かせください。
  2. 面談と審査秘密保持契約を結んだうえで状況をうかがい、お引き受けできるかを判断します。
  3. 方針の整理承継の形と時期、優先することを決めます。
  4. 引き継ぎの準備組織と業務を見える化し、後継者を育てます。
  5. 引き継ぎ後の支援新しい体制で組織を整え直します。

FAQよくあるご質問

  • まだ承継するか決めていない段階でも相談できますか。

    はい。決める前に、何を優先したいのかを整理するところからお手伝いします。

  • 福祉以外の事業でも相談できますか。

    はい。障害福祉・介護・保育などの福祉事業を中心にお受けしていますが、ほかの業種の方もまずはご相談ください。人と組織を引き継ぐ難しさは、業種を問わず共通しています。お引き受けできるかどうかは、面談のうえで判断します。

  • 補助金は使えますか。

    当社はM&A支援機関登録制度に登録していないため、当社への費用は事業承継・M&A補助金の専門家活用枠の対象になりません。
